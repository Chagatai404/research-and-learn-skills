# Defend

Open the real investigation, claim, diff, result and audit status. Pick a specific result the researcher wants to own. If artifacts are missing, identify the missing link; preserve what can be traced. Work in the investigation note following [study notes](../../references/study-notes.md). Keep evidence for claim validity separate from evidence of the learner's understanding.

Trace one quantity backwards from a plot/table value to its output row, function or notebook cell, transformation, inputs, assumptions and revision. Reconstruct the forward path in ordinary language. Use a tiny worked example or local read-only inspection. Execution of a notebook, training or altered experiment requires appropriate authorization; passive code inspection alone establishes only what is written.

Build rubric-backed free-response items for the relevant dimensions: derivation, baseline choice, falsifier, strongest rejection and response, code location and transformations. Follow [learn](../learn/SKILL.md) for probe, grade and delayed review. Ask one question, wait for the learner's own reconstruction, then change an assumption or context and ask for a prediction. For example: “If two groups in different folds share the same source event, which conclusion about this reported score changes?” Distinguish a missed idea from an incorrect claim about the actual code.

Record the exact dimension and assistance through the shared profile. Keep unowned, practising, demonstrated and delayed retention legible in prose, with open dimensions linked to further study. The learner alone may waive ownership. A waiver grants no mastery.
